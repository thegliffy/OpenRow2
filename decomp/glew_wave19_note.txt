GLEW 2012-era sweep (wave 19), 2026-10-12.

Wave 18 used the modern Khronos gl.xml, which misses extensions whose
function lists changed after the game shipped. This sweep regenerated the
lists from GLEW's own pinned-era specs: glew-1.8.0 tag (2012), auto/core and
auto/extensions spec files, function prototypes parsed directly (the repo's
make_init.pl needs a Perl @INC fix; not needed for set matching).

Twenty candidates matched exactly against the 2012 specs (string set == spec
function set, one extension each), and every body was verified to load
exactly that set through the proc-address loader — the _glewInit_<EXT>
pattern. Names use the generator's convention: _glewInit_ plus the extension
name verbatim, GLX_ prefix kept.

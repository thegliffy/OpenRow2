Three minidump entry points

042d0710 (1152 bytes), 042d0e50 (1248 bytes), and 042d1330 (848 bytes) each inline that constructor. The bodies differ.

After FUN_042d2330 builds the writer object, all three do the same thing:

- If the stored fd is -1 and the path pointer is null, call FUN_0400939e.
- If the fd is not -1 and the path pointer is set, call __assert_fail at minidump_writer.cc line 0x8d. The condition string these three reference is "fd_ == -1 || !minidump_path".
- Make a virtual call at offset 8. A false result returns 0.
- If the fd is -1, call google_breakpad::MinidumpFileWriter::Open. Otherwise call google_breakpad::MinidumpFileWriter::SetFile.
- Make a virtual call at offset 0x10. A true result then calls FUN_042ce600.
- If the fd is -1, call FUN_042d2420.
- Make a virtual call at offset 0x14, then call FUN_042d24a0.

- 042d0710 is __regparm2 and takes eight arguments. FUN_042cc800 builds the dumper from one argument. Two arguments are saved as list pointers. The context pointer may be null, and then no context is copied. A non-null context is accepted only when the following integer is 0x250. The copy takes word 0, word 3, word 0x20, and the spans that start at word 0x21 and word 0x78. Any other size returns 0. The dumper is destroyed with FUN_042c9eb0. The call catalog records two callers, 042d0b90 and 042d0c90, each 256 bytes. Each also calls operator.delete twice.

- 042d0e50 takes three arguments. The first is stored as the path, the second is passed to FUN_042cc800, and the third is stored next to an fd of -1. It has no 0x250 test. It builds two empty circular lists and frees their nodes with operator.delete. It destroys the dumper with FUN_042c9eb0.

- 042d1330 takes four arguments. The first is stored as the path, and the fd is set to -1. The fourth argument is an existing object: the function reads offsets 0x14, 0x1c, and 0x20, and it does not call FUN_042cc800. It does not free list nodes, and it does not call FUN_042c9eb0.
